# SWS Trading Enterprises (Pvt) Ltd. Website

A responsive static business website for SWS Trading Enterprises, designed for GitHub Pages.

## Files

- `index.html` — page content and structure
- `style.css` — responsive design and styling
- `script.js` — mobile navigation, product enquiry buttons and WhatsApp quotation form

## Before publishing

1. Open `script.js`.
2. Replace `923000000000` in `SWS_WHATSAPP_NUMBER` with your official WhatsApp number, using country code and digits only. Example format: `923001234567`.
3. In `index.html`, replace `[Add company address]`, `[Add phone number]`, and `[Add official email]` with your real business details.
4. Review product descriptions and confirm that they accurately reflect your business.
5. Images are loaded from Unsplash and Google Fonts are loaded online, so those elements need an internet connection.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `sws-trading-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub Pages to publish your site; the public URL will appear in the Pages settings.

## Quotation form note

The form prepares a quotation message and opens WhatsApp so the visitor can review and send it. It does not automatically submit or store form data. The WhatsApp number must be configured in `script.js`.
